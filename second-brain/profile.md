# Profile — Morgan Godvin

Drug-policy researcher whose work joins lived experience with epidemiology — "science meets
humanity." Public site: [morgangodvin.github.io](https://morgangodvin.github.io).

  brand kit, manuscripts, site). See [`projects/dcla.md`](projects/dcla.md).

  [`projects/ucla-shover-lab.md`](projects/ucla-shover-lab.md).
- **OHSU** — MPH student (Biostatistics BSTA 525 summer, PHE 522 fall). See
  [`projects/ohsu-mph.md`](projects/ohsu-mph.md).
- **The Influence Foundation (TIF)** — board member. See
  [`projects/influence-foundation-board.md`](projects/influence-foundation-board.md).
- **Doctors for Drug Policy Reform (D4DPR)** — harm-reduction influencer-landscape work with
  The Action Lab at Northeastern. See [`projects/d4dpr-influencer-landscape.md`](projects/d4dpr-influencer-landscape.md).
- **Northeastern — The Action Lab** — affiliation for the influencer-landscape synthesis.
